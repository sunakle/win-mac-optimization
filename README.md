# Win Mac Optimization

Восстановление тёмного оформления и рабочих инструментов после переустановки Windows. Скрипты рассчитаны на Windows 10; на Windows 11 неподдерживаемые пункты пропускаются. Установщик сначала показывает план и сохраняет резервную копию затрагиваемых настроек Windows.

## Быстрый старт

Откройте PowerShell **под своей учётной записью** в папке репозитория:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\Install.ps1                 # только проверка и план
.\Install.ps1 -Apply          # применить базовое оформление
.\Check.ps1                   # проверить результат
```

Администратор для базового оформления не нужен. Если на новом ПК нет нужной программы, `Install.ps1 -InstallApps -Apply` установит Docker Desktop, Ollama, ShareX, Obsidian и Git через WinGet. Это отдельный необязательный шаг, который может запросить права администратора. Программы Adobe, игры и платные пакеты автоматически не устанавливаются.

## Что восстанавливается

| Компонент | Действие |
|---|---|
| Windows | Тёмные приложения и система, небольшой размер панели задач, скрытая погода и кнопка Task View, расширения файлов видны |
| Папки | Создаётся оригинальная голубая иконка, назначается как стандартная для новых и существующих папок |
| Рабочий стол | По желанию устанавливаются свои обои из `local-assets` |
| TaskbarX | Если положить официальный ZIP в `local-assets`, устанавливается центрирование и автозапуск без акрилового размытия |
| Диск C | Отдельный скрипт показывает и удаляет только старые временные файлы |
| DeepSeek | Отдельный Docker-набор с рабочей папкой, ограниченным доступом к сети и проверкой готовности |
| Ollama | Отдельный импорт скачанного GGUF, без подключения к DeepSeek |

Не включены прежний скрипт принудительного скругления окон (он мешал перетаскиванию), подмена стрелки ярлыка (вызывала чёрные квадраты), сомнительные «твики FPS», отключение Defender и публикация ключей или переписок.

## Свои файлы

Папка `local-assets` специально исключена из Git. После сброса ПК положите туда:

- `wallpaper.png` — свои обои; без него текущие обои не меняются;
- `TaskbarX.zip` — официальный портативный архив [TaskbarX](https://github.com/ChrisAnd1998/TaskbarX/releases); без него центрирование не включается;
- при желании исходный `.theme`/`.msstyles` и архивы тем; их установка остаётся ручной, поскольку они меняют системные файлы и зависят от версии Windows;
- GGUF модели для локальной Ollama. Файлы моделей в публичный Git не добавляются.

Для точного восстановления **своих текущих** значков, обоев, курсоров и темы до сброса ПК выполните `.\Export-PrivateAssets.ps1 -Destination 'G:\MacStyle-private.zip'` и сохраните ZIP отдельно. После переустановки распакуйте его и передайте иконки установщику: `.\Install.ps1 -Apply -IconDirectory 'G:\MacStyle-private\Icons\Yosemite' -WallpaperFile 'G:\MacStyle-private\Wallpapers\Anime-Graphite.png'`. Архив не отправляется в GitHub. Файлы `.theme` и `.msstyles` внутри него требуют отдельной совместимой установки; скрипт их автоматически не применяет.

Если нужна вся доступная автоматическая часть прежнего оформления, после распаковки архива используйте один скрипт:

```powershell
.\Restore-PrivateStyle.ps1 -AssetsRoot 'G:\MacStyle-private'        # план
.\Restore-PrivateStyle.ps1 -AssetsRoot 'G:\MacStyle-private' -Apply # значки, обои, звуки, курсоры, центрирование
```

Скрипт сохраняет прежние настройки курсоров и звуков в `backups/`, копирует личные файлы в профиль, переименовывает пути внутри темы под новую учётную запись и применяет безопасные пользовательские настройки. Архив на G: должен быть заранее распакован. Тема Big Sur и её кнопки окон остаются ручным шагом: `.msstyles` зависит от версии Windows и стороннего патчера. Значки дисков и оформление диалогов сторонних программ не гарантируются. Для полной копии прежней системы также понадобятся установщики программ, личные настройки приложений, Docker-тома и модель GGUF.

На этом ПК часть оформления пришла из сторонних архивов macOS/Big Sur. Этот репозиторий не копирует их содержимое и не обещает точного вида нестандартных диалогов во всех программах. Windows и приложения могут рисовать окна самостоятельно.

## Резервная копия и откат

При `-Apply` перед изменениями создаётся `backups/<дата>/state.json` со значениями затрагиваемых параметров. Папка исключена из Git. Для отката:

```powershell
.\Undo.ps1 -BackupPath .\backups\2026...\state.json
```

Храните собственные обои, GGUF и установщики отдельно: публичный репозиторий намеренно не хранит чужую графику, дистрибутивы и личные данные. После смены значков может потребоваться выход из учётной записи и повторный вход.

## Дополнительные команды

```powershell
.\Clean-Temp.ps1                     # оценка объёма старых временных файлов
.\Clean-Temp.ps1 -Apply              # очистка только найденных временных файлов
.\deepseek\Setup.ps1                 # план установки изолированного DeepSeek
.\deepseek\Setup.ps1 -Apply          # сборка и запуск, если Docker уже установлен
.\ollama\Import-GGUF.ps1 -ModelPath 'D:\Models\model.gguf' -Name 'gpt4chan-chat'
```

DeepSeek после новой установки требует входа и выбора модели в его интерфейсе. Старые чаты и ключи хранятся в томе Docker и **не входят** в репозиторий. Для их переноса сделайте отдельную личную резервную копию тома. `docker compose down -v` удалит их, поэтому скрипты используют `stop`.

## Проверка и ограничения

`Check.ps1` печатает значения темы, состояние значков, TaskbarX, Docker и Ollama. Не все изменения можно проверить без визуального просмотра. Проверьте новую папку в Проводнике и перемещение окон на каждом мониторе. Если сторонняя тема или программа снова вызовет рывки, отключите её отдельно: скрипт Windows не меняет драйвер видеокарты и частоту монитора.

Команды рассчитаны на запуск из распакованного репозитория. Повторный запуск безопасен: он обновляет те же значения и не стирает пользовательские файлы. `Install.ps1` не запускает очистку диска и не перезапускает Windows.

Точное соответствие прошлой настройке и ограничения каждого пункта описаны в [RESTORE-MAP.md](RESTORE-MAP.md).
