# Карта восстановления

| Что было настроено в этом чате | Где восстанавливается | Ограничение |
|---|---|---|
| Тёмная Windows и Проводник | `Install.ps1` | Сторонние программы рисуют собственные окна; универсального безопасного переключателя для всех диалогов нет |
| Голубые папки по умолчанию | `New-FolderIcon.ps1` + `Install.ps1`; точный прежний набор через `-IconDirectory` | Иконка в репозитории создана заново; сторонние Yosemite-файлы остаются в личном архиве |
| Маленькая панель задач, погода скрыта | `Install.ps1` | Размер и виджет относятся к Windows 10; на Windows 11 пропускаются |
| Центрирование значков | `Install.ps1` при наличии TaskbarX ZIP или `Restore-PrivateStyle.ps1` из личного архива | Исполняемый файл TaskbarX не публикуется в GitHub |
| Тёмные аниме-обои, курсоры и системные звуки | `Restore-PrivateStyle.ps1` из личного архива | Личные и сторонние файлы не публикуются в открытом GitHub |
| Темы Big Sur/macOS и кнопки окон | Файлы подготовлены в личном архиве; установка темы вручную | `.msstyles` зависит от версии Windows и стороннего патчера; автоматическое применение может нарушить работу окон |
| Значки дисков и тёмные диалоги всех программ | Не гарантируется | Отдельные приложения и Windows рисуют интерфейс по-своему; универсального безопасного переключателя нет |
| Скругление окон | Не восстанавливается | Старый скрипт портил перетаскивание и давал пиксельные края |
| Удаление стрелок ярлыков | Не восстанавливается | Подмена вызывала чёрные квадраты при переносе значков |
| Очистка диска C | `Clean-Temp.ps1` | Только старые временные файлы; документы, загрузки и корзина не затрагиваются |
| DeepSeek в Docker | `deepseek/Setup.ps1` | Чаты, ключи, сторонние плагины и индивидуальные цвета профиля находятся в личном томе Docker и не публикуются |
| GPT4chan для переписки | `ollama/Import-GGUF.ps1` | Скачанный GGUF необходимо хранить отдельно; модель не подключается к DeepSeek |
| Закреплённые приложения в Пуске | Восстановить вручную после установки приложений | Windows не предоставляет стабильный перенос личного списка между выпусками ОС |
| Рывки окон и значков на 165 Гц | Диагностика в `Check.ps1`; вредные эффекты не включаются | Причина зависит от драйвера и мониторов; скрипт не меняет видеодрайвер или частоту |

Текущие локальные пути пользователя намеренно не зашиты в скрипты. После сброса учётная запись и буквы дисков могут измениться. В `backups/` хранится откат только для изменений, внесённых этим набором; для полного переноса старой установки нужен отдельный личный бэкап файлов оформления, Docker-тома и GGUF.
